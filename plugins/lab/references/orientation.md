# Agent Lab — Orientation

This is the short introduction the tutor presents at `/lab:start`. Keep it short: the
participant has three more steps to get through before the training begins.

---

## What this is

An 8-hour hands-on training in **AI fluency** — how to go from understanding how AI agents
work to **building a full AI system** that accomplishes real, complex work.

Four modules, two hours each:

| Module | | |
|---|---|---|
| **1** | **Harness and coding agent** | What an agent is, what the harness is made of, and how to extend it |
| **2** | **RAG and retrieval systems** | Grounding the agent in your own documents — and measuring whether it worked |
| **3** | **Knowledge graphs and ontologies** | The questions retrieval cannot answer, and the semantic layer that can |
| **4** | **The full AI system** | Validating and improving it until it is production-ready and delivers real value |

## How we run it

Through this plugin. **The plugin is a tutor.**

It teaches each module's concepts by having you build **one real-world example**, and you
build on top of that same example in every module. Module 1 lays the foundation. Modules 2
and 3 add retrieval and a knowledge layer. Module 4 is about validating and improving what
you have built until it is production-ready and actually delivers value.

The tutor:

- **sets up** your lab
- **teaches** the concepts, module by module
- **guides you** while you build
- **validates** your work before you move on

You build it. You keep it. It runs on your machine.
